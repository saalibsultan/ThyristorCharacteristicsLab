# Thyristor Characteristics Lab

Overview
Laboratory documentation and measurement log for studying the static and dynamic characteristics of a Thyristor (SCR) using a power electronics training system. This repository covers circuit wiring, firing angle control, and empirical verification using standard bench instruments.

Specifications & Components
- Supply Voltage (Vs): 45 V (AC)
- Protection Fuse (F)
- Series Resistor: 100 ohm
- Load Resistor: 200 ohm
- Semiconductor Device: Thyristor (SCR) / Diode modules

Equipment
- Power Electronics Trainer Board / Modular Panel
- AC Power Supply Module
- Firing Circuit / Pulse Generator
- Alpha Controller (Firing Angle Control)
- Digital Multimeters (Voltmeter & Ammeter)
- Oscilloscope

Circuit Configuration
- Firing circuit connected to Gate (G) and Cathode (K) terminals of the SCR.
- Voltage measurements recorded across load components.
- Current monitored via in-line ammeter and oscilloscope probes.
